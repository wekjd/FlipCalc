# FlipCalc

Умный финансовый помощник для перепродажи: калькулятор прибыли с комиссиями площадок, конвертер валют, учёт товаров и сделок, аналитика, цели, подключение к Yoomarket и Telegram-бот.

Работает локально на вашем компьютере: небольшой сервер на Python + страница в браузере.

## Возможности

- **Прибыль:** наценка, цена продажи, желаемая прибыль, безубыток, таблица наценок; профили комиссий площадок (Playerok, DIP-X, YooMarket и свои)
- **Конвертер** валют и криптовалют
- **Товары, аналитика, цели** — учёт закупок, сделок и планов заработка
- **Объявление:** подготовка текста, **шаблоны объявлений**, создание черновика через API Yoomarket
- **Инструменты:** сравнение площадок, партия товаров, график прибыли, экспорт в CSV
- **Языки:** русский, English, Українська, Deutsch, Español (кнопка «Сбросить язык» возвращает русский)
- **Светлая и тёмная тема**
- Кнопки быстрого копирования результатов
- Резервная копия данных одним текстом
- Telegram-бот и Mini App (по желанию)

## Запуск (Windows)

1. Установите [Python](https://www.python.org/downloads/) — при установке поставьте галочку **Add Python to PATH**.
2. Скачайте этот репозиторий (**Code → Download ZIP**) и распакуйте.
3. Дважды щёлкните по `ЗАПУСК.bat`. Откроется `http://localhost:8000`.
4. Окно с чёрным фоном не закрывайте, пока пользуетесь программой.

Для Telegram Mini App нужен компонент **OpenSSH Client** (Параметры → Приложения → Дополнительные компоненты). Он открывает временный публичный адрес через localhost.run.

Запуск вручную:

```
pip install fastapi uvicorn httpx
python -m uvicorn yoo_proxy:app --host 127.0.0.1 --port 8000
```

## Где хранятся данные

Ключи, токены ботов и настройки лежат только на вашем компьютере: `%APPDATA%\FlipCalc` (без `APPDATA` — в папке `data` рядом с программой). В репозиторий они не входят и закрыты в `.gitignore`. Никуда, кроме Yoomarket и Telegram, данные не отправляются.

**Никогда не публикуйте свои токены.** Если токен попал в чужие руки, перевыпустите его в панели магазина или у @BotFather.
